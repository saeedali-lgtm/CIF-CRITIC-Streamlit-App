# CSF Research — Dream Edition

Circular Spherical Fuzzy Sets (CSF) · CSF–SWARA weighting and CSF–CoCoSo ranking

Developed by Dr. Saeed Alinejad, Shiraz University, Iran.

[Open the web application](https://saeedali-lgtm.github.io/CIF-CRITIC-Streamlit-App/) · [Downloads and installation files](https://github.com/saeedali-lgtm/CIF-CRITIC-Streamlit-App/releases/latest)

The Dream theme uses deep teal, champagne gold, and light research workspaces. Web and Android version 2.0.3 share the same bundled interface, with a sculpted three-dimensional header. Calculations are performed on the device.

- Root files: standalone web application, hosted through GitHub Pages.
- Release file 03 includes Android source and build instructions. Android 8+; original signing key required for compatible updates.
- Release file 03 includes existing Python/Streamlit desktop source with the Dream theme. The release contains a portable Windows package; its launcher remains the existing version.
- `csf_mobile/`: server-based Streamlit edition, with the coordinated theme.
- `EDIT_CONTENT_2027.md`: Persian/English instructions for editing website text.

Use the template for the selected method, import Excel, review parameters, calculate, and export results before closing. Examples are synthetic. Review the method notes and release validation report. Numerical agreement with the reference implementation does not establish scientific validation. Signing keys and credentials are excluded. No new license is assigned to the research code; third-party license notices are retained.
