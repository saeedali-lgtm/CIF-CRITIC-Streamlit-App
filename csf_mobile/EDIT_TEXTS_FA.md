# راهنمای ویرایش نوشته‌های برنامه

برای تغییر نوشته‌های نسخهٔ آنلاین، فقط **[ui_texts.json](ui_texts.json)** را ویرایش کنید. نیازی به تغییر فایل‌های Python ندارید.

## مراحل

۱. در گیت‌هاب وارد حساب خود شوید و فایل `csf_mobile/ui_texts.json` را باز کنید.

۲. روی مداد **Edit this file** بزنید.

۳. عبارت سمت راست هر خط را تغییر دهید. نام سمت چپ را ثابت نگه دارید. مثلاً:

```json
"developer_name": "Dr. Saeed Alinejad"
```

۴. **Commit changes** را بزنید و تغییرات را در شاخهٔ `main` ثبت کنید.

۵. پس از به‌روزرسانی Streamlit، صفحهٔ برنامه را رفرش کنید.

## مهم‌ترین قسمت‌ها

| نام در فایل | نوشته‌ای که کنترل می‌کند |
| --- | --- |
| `page_title` | عنوان تب مرورگر |
| `brand` | نوشتهٔ کوچک بالای عنوان |
| `title` | عنوان اصلی صفحه |
| `subtitle` | توضیح زیر عنوان |
| `methods` | معرفی کوتاه روش‌ها زیر عنوان |
| `developer_label` | عنوان نقش توسعه‌دهنده |
| `developer_name` | نام توسعه‌دهنده |
| `affiliation` | دانشگاه یا وابستگی سازمانی |
| `extra_note` | نوشتهٔ اختیاری جدید زیر سربرگ و بالای تب‌ها |
| `swara_tab` و `cocoso_tab` | نام تب‌های دو روش |
| `swara_intro` و `cocoso_intro` | توضیحات ابتدای هر روش |
| `swara_upload` و `cocoso_upload` | عنوان بخش بارگذاری |
| `swara_empty` و `cocoso_empty` | راهنمای قبل از بارگذاری فایل |
| `swara_download` و `cocoso_download` | نوشتهٔ دکمهٔ دریافت نتایج |
| `swara_about` و `cocoso_about` | توضیحات بخش دربارهٔ ابزار |
| `method_note` و `privacy_note` | توضیحات روش و پردازش داده |

## کم و زیاد کردن نوشته‌ها

- برای اضافه کردن توضیح جدید، داخل مقدار `extra_note` بنویسید. برای حذف آن، مقدار را به `""` برگردانید.
- متن `subtitle`، `methods` و `affiliation` را نیز می‌توانید با قرار دادن `""` پنهان کنید.
- بقیهٔ نوشته‌ها را می‌توانید کوتاه یا بلند کنید؛ برچسب دکمه‌ها و عنوان‌ها را خالی نگذارید.
- متن فارسی و انگلیسی پذیرفته می‌شود؛ چیدمان فعلی برای انگلیسی طراحی شده است.
- برای دو خط شدن یک توضیح معمولی از `\n` استفاده کنید. عنوان‌ها و توضیحات سربرگ به‌صورت متن ساده نمایش داده می‌شوند.
- نام‌های سمت چپ را حذف یا عوض نکنید و کلید جدید نسازید؛ کلیدهای ناشناخته نمایش داده نمی‌شوند.
- ویرگول‌ها و علامت‌های نقل‌قول انگلیسی `"` را حفظ کنید. برای نوشتن نقل‌قول داخل متن از `\"` استفاده کنید.

اگر فایل از نظر نگارش JSON نامعتبر شود، برنامه با متن‌های پیش‌فرض اجرا می‌شود و پیام هشدار نشان می‌دهد. مقدارهای اشتباه نیز با متن پیش‌فرض همان قسمت جایگزین می‌شوند. در صورت حذف ناخواستهٔ یک کلید، متن پیش‌فرض آن حفظ خواهد شد.

## محدودهٔ تغییرات

این فایل فقط نوشته‌های نمایشی برنامه را کنترل می‌کند. روابط ریاضی، نام ستون‌های Excel، ساختار ورودی و خروجی و پیام‌های فنی اعتبارسنجی در کد اصلی باقی می‌مانند. نوشته‌های خود Streamlit مانند Upload یا Share از این فایل تغییر نمی‌کنند.

در اپلیکیشن اندروید، نوشته‌های محتوای آنلاین نیز با این تغییرات به‌روز می‌شوند؛ اما عنوان و نام توسعه‌دهنده در سربرگ بومی اندروید مستقل است و تغییر آن به ساخت APK جدید نیاز دارد.

برای بازگردانی نوشته‌های قبلی، تاریخچهٔ همین فایل در گیت‌هاب (**History**) را باز کنید و مقدارهای نسخهٔ قبلی را دوباره در فایل ثبت کنید.
